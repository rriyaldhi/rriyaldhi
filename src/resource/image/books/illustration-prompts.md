# Book illustration prompts

Generated with the built-in image generation tool. The JPEG assets in this directory are used by `src/component/books.ts`.

## Shared prompt

Create one square book cover emblem or book-page editorial scene for a minimalist reading website. Pure black ink on pure white. Covers use bold woodcut silhouettes and detailed crosshatching; pages use delicate pen-and-ink lines, natural proportions, and fine crosshatching like an illustrated literary essay. Center the composition with generous white margins. No text, captions, labels, watermark, border, gray background, or colored elements. Keep it readable at small sizes.
